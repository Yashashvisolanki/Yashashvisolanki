
# Elderly Digital Payment App

## Project Overview
A UI/UX design project focused on improving digital payment experiences for elderly users.

## Problem Statement
Many elderly users experience difficulties using digital payment applications because of complicated navigation, small text, confusing instructions, and lack of accessibility features.

## Research
- User interviews
- Background research
- Competitor analysis
- User observations

## Research Findings
- Difficulty understanding complex interfaces.
- Need for larger buttons and readable text.
- Preference for familiar language.
- Need for clear transaction confirmation.

## Design Process
1. Problem identification
2. User research
3. Empathy mapping
4. Affinity mapping
5. User journey mapping
6. User flows
7. Wireframing
8. UI design
9. Prototype and testing
